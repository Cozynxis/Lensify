# Lensify

Lensify is a smooth, lightweight zoom mod for Minecraft 26.2 on Fabric.

## Features
- Smooth animated zoom
- Mouse-wheel zoom steps
- Hold or toggle zoom mode
- Configurable zoom strength
- Adjustable animation speed
- Optional sensitivity scaling while zoomed
- Three presets: Soft, Balanced, Deep
- Mod Menu configuration screen
- Client-side only
- No raw OpenGL calls

## Defaults
- Zoom key: C
- Settings key: V
- Hold mode
- 4x zoom
- Smooth easing enabled
- Scroll zoom enabled

## Requirements
- Minecraft Java 26.2
- Fabric Loader 0.19.3+
- Fabric API
- Java 25
- Mod Menu optional

## Building
Run:
```bash
gradle build
```

The playable JAR will be created in `build/libs/`.
